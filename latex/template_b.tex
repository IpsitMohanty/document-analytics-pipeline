\section*{Selected Systems Built \& Shipped}

\noindent{\small Independently built at \textbf{\href{%%TRACKER_GH%%}{github.com/IpsitMohanty}}: each system starts from a problem observed in programme operations.}\\[0.5mm]

\begin{itemize}[itemsep=2pt]
\item \textbf{\href{%%TRACKER_REPO_POSHAN%%}{Poshan Intelligence Pipeline}:} End-to-end data platform with 12 ETL modules for distinct report types, a district-level analytics cube, and RandomForest models predicting low-birth-weight and stunting rates, served via FastAPI. Dockerised, with CI (pytest, flake8, mypy).
\item \textbf{\href{%%TRACKER_REPO_AWC%%}{AWC Operations Dashboard}:} Operations analytics platform with staging-to-fact-table design, anomaly/risk/alert scoring, and schema-drift detection across monthly exports; dual-backend Streamlit app deployed on Streamlit Community Cloud with managed PostgreSQL (Neon). Runs on synthetic data modelled on public nutrition-program reporting formats. \href{%%TRACKER_DEMO_AWC%%}{Live demo}.
\item \textbf{\href{%%TRACKER_REPO_REC%%}{Course Recommender System}:} Built and evaluated nine recommendation approaches under a common interface, with a reproducible held-out evaluation and a 63-test suite; deployed as an interactive Streamlit app. The analysis surfaces an honest result, with only a clustering approach outperforming a simple popularity baseline. \href{%%TRACKER_DEMO_REC%%}{Live demo}.
\item \textbf{\href{%%TRACKER_REPO_RAG%%}{RAG Ingestion Evaluation}:} A document question-answering pipeline over public nutrition-programme documentation (app FAQs and scheme guidelines), with a structured evaluation of retrieval quality. Key finding: the system's confidence scores cannot reliably distinguish a correct answer from nothing relevant, a practical limitation for any deployed RAG assistant. Tested, deployed, with a \href{%%TRACKER_DEMO_RAG%%}{live demo}.
\end{itemize}
